# Proveniência das amostras
Os dois ficheiros JSON e CONTRATO_MT01_ORIGINAL.md são cópias, sem alteração,
fornecidas no MT01_Exemplos_Comentados.zip. Origem didática: MT01, EX02.
`indice_demo` e `u_demo` são fictícios. Não se trata do formato HKT ou TTN.
O instante received_at pertence ao conjunto de demonstração; não é a hora de
execução desta aula. measured_at=null continua a indicar instante desconhecido.
O contrato integral MT01 é incluído para consulta; GL01 só projeta sete campos
já conhecidos. Não há validação integral, idempotência ou aquisição física.
Não alterar estas duas amostras durante o percurso obrigatório.
